Tools of the trade

The tools for disassembly

The first special tool you will need to disassemble the transmission is the P37 or P37a tool
however this tool is optional, I use an impact wrench from Ryobi that works well. Just make sure to
spray the bolts to loosen them a bit before going to work on them.

The second spceial tool you will need (and this tool is quite difficult to find) is the P355a tool. This tool is going to hold the input shaft so you can turn the bolt holding all the gear together. There are some workarounds if you dont find these tools. One can use an old fifth gear as this has the same dimensions as the P355a tool. An other option is to fasten the input shaft from the other side by using a clutch disk as this has the same teeth dimesions as the P256 tool.

The third and fourth special tools you need is the tools to dissassemble the gears from each other.
